# 《佛系消消消》自动刷关副本

一个基于计算机视觉和回溯算法的游戏辅助程序，自动识别网格、求解谜题并完成点击操作。

## 功能特性

- **自动网格识别**：通过图像处理自动识别网格大小（4x4 到 15x15）和每个格子的颜色
- **智能求解算法**：使用回溯算法 + 约束传播 + 启发式优化，高效求解谜题
- **自动点击操作**：将求解结果映射到屏幕坐标，自动双击完成游戏
- **防检测机制**：添加随机位置和时间误差，避免被识别为自动化程序

## 项目结构


## 使用方法

### 1. 定位游戏窗口

⚠️ **重要：首次使用前需要手动定位游戏窗口位置！**

运行 `screen_detect.py` 查看当前截图区域，根据实际情况修改 `main.py` 中的 `region` 参数：

```python
region = (x_offset, y_offset, width, height)
```

参数说明：
- `x_offset`: 游戏窗口左上角的 X 坐标
- `y_offset`: 游戏窗口左上角的 Y 坐标
- `width`: 游戏窗口的宽度
- `height`: 游戏窗口的高度

### 2. 运行程序

```bash
python main.py
```

程序会自动执行以下循环：
1. 截取游戏窗口
2. 识别网格大小和颜色
3. 使用算法求解谜题
4. 自动点击牛的位置
5. 等待 5 秒后继续下一轮

### 3. 退出程序

按 `Ctrl + C` 退出程序。

## 算法原理

### 网格识别

1. **背景色检测**：通过图像边缘像素的众数确定网格线颜色
2. **投影法找网格线**：将背景色掩码进行行列投影，使用峰值检测找到网格线位置
3. **颜色聚类**：使用贪心算法将相近颜色聚类，按首次出现顺序编号

### 求解算法

1. **回溯算法**：深度优先搜索，逐行放置牛
2. **约束传播**：
   - 锁定候选排除：如果连续 n 行/列只包含 n 种颜色，排除这些颜色在其他位置
   - 行/列/颜色有效性检测：快速剪枝
3. **启发式优化**：最小剩余值（MRV）启发式，优先选择约束最强的位置

### 约束条件

- 每行只能放置一头牛
- 每列只能放置一头牛
- 对角线相邻格子不能有牛
- 必须覆盖所有颜色

## 注意事项

- 确保游戏窗口在运行过程中位置不变
- 程序运行时不要移动鼠标或干扰操作
- 不同分辨率或游戏版本可能需要调整 `region` 参数
- 如识别失败，程序会等待 5 秒后重试

## 常见问题

**Q: 识别不准确怎么办？**

A: 调整 `grid_location.py` 中的 `eps` 参数（默认 35），值越小分类越细，值越大合并越多。

**Q: 求解速度慢怎么办？**

A: 算法已优化，12x12 网格通常在 0.5 秒内完成。如果仍慢，检查是否有多个解的情况。

**Q: 点击位置不准确？**

A: 检查 `main.py` 中的 `region` 参数是否与实际游戏窗口匹配。
